# Attributes and Tags

Use these optional attributes and tags to control the system:

- `H4S_KeepMaterial = true` protects a part's material and color.
- `H4S_Preserve = true` protects an object from material correction.
- `H4S_ForceMaterial = true` increases material correction strength.
- `H4S_Style` on `Workspace` sets the global visual style.
- `H4S_PreserveAesthetic` controls how strongly the original style is preserved.
- `H4S_KeepLight = true` protects a local light from distance budgeting.
- `H4S_KeepParticles = true` protects a particle emitter from distance budgeting.

Equivalent tags supported by the system include `H4S_KeepMaterial`, `H4S_Preserve`, and `H4S_ForceMaterial`.

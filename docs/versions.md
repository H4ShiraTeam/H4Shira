# Versions

## V1

A small base setup for Future Lighting, atmosphere, water, Bloom and SunRays.

## V2

Adds basic material adjustments and periodic lighting updates.

## V3

Adds camera priority, material preservation and time-of-day exposure.

## Latest

Adds map profiling, contextual material work, local-light and particle budgets, and separate frame-time and script-time controls.

All versions are LocalScripts and use public Roblox APIs. They are not drop-in replacements for one another; choose the version that fits the place and target devices.
